# 🖥️ MikroTik Configuration Guide

Веб-додаток для налаштування та керування MikroTik роутерами. Інтерактивний посібник з покроковими інструкціями, скріншотами та детальними налаштуваннями для різних сценаріїв використання.

## 📋 Опис

Цей проект є комплексним посібником для налаштування MikroTik роутерів, який включає:

- **Загальні положення** - основні принципи та загальна інформація
- **Базові налаштування** - налаштування мережі, DHCP, маршрутизації
- **Резервне підключення** - налаштування резервних каналів зв'язку
- **Налаштування захисту** - конфігурація безпеки та firewall
- **Скрипти** - автоматизація налаштувань через скрипти
- **L2TP + EOIP** - налаштування VPN з'єднань та тунелів

## ✨ Основні функції

- 📱 **Адаптивний дизайн** - працює на всіх пристроях (десктоп, планшет, мобільний)
- 🖼️ **Галерея зображень** - інтерактивні скріншоти з можливістю перегляду в повному розмірі
- 🎨 **Сучасний UI** - красивий градієнтний дизайн з плавними анімаціями
- 🔍 **Модальні вікна** - зручний перегляд зображень у повноекранному режимі
- 📚 **Покрокові інструкції** - детальні покрокові керівництва для кожного налаштування
- 🔄 **Акордеон-блоки** - організована структура з можливістю розгортання/згортання

## 🛠️ Технології

- **React 19.1.1** - бібліотека для створення користувацьких інтерфейсів
- **Vite 7.2** - швидкий інструмент збірки та розробки
- **CSS Modules** - модульні стилі для компонентів
- **React Hooks** - для управління станом та побічними ефектами

## 📦 Встановлення

1. Клонуйте репозиторій або завантажте проект
2. Встановіть залежності:

```bash
npm install
```

## 🚀 Запуск проекту

### Режим розробки

```bash
npm run dev
```

Проект буде доступний за адресою `http://localhost:5173`

### Збірка для продакшну

```bash
npm run build
```

Зібраний проект буде в папці `dist/`

### Попередній перегляд зібраного проекту

```bash
npm run preview
```

## 🎯 Основні розділи

### 📋 Загальні положення
Загальна інформація про MikroTik та основні принципи роботи.

### ⚙️ Базові налаштування
- Налаштування мережевих інтерфейсів
- Конфігурація DHCP
- Налаштування маршрутизації
- Firewall та NAT

### 🔄 Резервне підключення
Налаштування резервних каналів зв'язку для забезпечення безперебійної роботи.

### 🛡️ Налаштування захисту
Конфігурація безпеки, firewall правил та захисту від загроз.

### 📜 Скрипти
Автоматизація налаштувань через скрипти RouterOS.

### 🔗 L2TP + EOIP
Детальні інструкції з налаштування:
- L2TP Server та Client
- EOIP тунелі між роутерами
- Віддалений доступ ROMON
